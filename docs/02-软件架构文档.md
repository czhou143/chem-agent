# 软件架构文档
- 语言：Python 3.11；依赖 rdkit、openai 兼容 SDK（可接 DeepSeek 或其他模型）、pytest
- 目录结构：
  - chem_agent/tools.py     RDKit 工具函数和工具描述（JSON schema）
  - chem_agent/agent.py     ReAct / function-calling 主循环
  - eval/questions.jsonl    评测题
  - eval/run_eval.py        自动评分脚本
  - tests/                  单元测试
- 数据流：用户提问 → LLM 决定调用哪个工具 → RDKit 计算 → 结果返回 LLM → 生成最终回答 → 评测脚本对比标准答案
- 模型 API Key 通过环境变量 LLM_API_KEY 读取，不写进代码仓库。
- 其他 agent 接手时：先读 01 需求文档和 03 进度文档，再看本文件。
