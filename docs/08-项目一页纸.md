# Chem Agent｜化学 Agent 开发与评测

## 目标

面向 ByteIntern（Agent 开发/评测）的简历作品，把化学背景与 Agent 工程结合，提供可运行、可核验的项目证据。[需求](01-需求文档.md)

## 架构

DeepSeek function-calling 主循环选工具，RDKit 计算后回传模型生成回答。共 **8 个工具**：分子量、LogP、分子式、TPSA、氢键、Lipinski、相似度、`safety_check`。[工具](../chem_agent/tools.py)

HBA 采用 RDKit `NumHAcceptors`（咖啡因 **3**）；Lipinski 原文另用 N+O 计数，咖啡因分子式 C8H10N4O2 对应 **6**，实现未改。[定义与记录](../README.md)

**同一套工具，两种暴露方式**：Agent 通过 function calling 调用；官方 SDK 的 MCP stdio 封装供外部客户端调用，复用化学逻辑。**Cursor 已实测**（[工具列表截图](images/cursor-mcp-tools.webp)／[调用截图](images/cursor-mcp-call.webp)）；**Claude Desktop 未测**。[架构](../README.md)

## 安全边界

`safety_check` 使用 Brenk + NIH：DOI **10.1002/cmdc.200700139**、**10.1021/jm901070c**。[来源](../README.md)

免责声明：仅基于结构的规则粗筛（药物化学警示库），不是毒性或爆炸性评估，请以 MSDS/SDS 为准。系统指令要求拒绝合成路线或制备方法；MCP 宿主仍须遵守。
