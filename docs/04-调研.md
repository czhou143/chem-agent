## 逐个分析
### ChemCrow
- 工具设计：LangChain ReAct + 约 18 个工具，按模块分为 rdkit（分子量、相似度、官能团）、search（文献/网页）、converters（名称↔SMILES）、reactions（RXN4Chem 反应预测）、safety（管制/爆炸物检查）、chemspace（购买价格）。每个工具一个类，带自然语言描述供 LLM 选择。
- 评测：14 个任务由化学专家盲评 + GPT-4 评审对比，结论是 LLM 当评委会偏向“看起来流畅”的答案。
- 借鉴：①工具按模块拆文件；②加“安全检查”工具是亮点；③评测别只靠 LLM 评委，要有可程序化判定的标准答案。

### K-Dense-AI/scientific-agent-skills
- 工具设计：不写 Agent 框架，而是写 SKILL.md（说明文档 + 示例脚本），让 Claude Code/Codex 等现成 Agent 按需加载；化学部分覆盖 RDKit、PubChem、ChEMBL、DeepChem 等。
- 评测：以技能“经过验证可运行”为主，没有统一量化基准。
- 借鉴：项目最后可额外导出一个 SKILL.md，让作品同时兼容 Codex/Claude Code，紧跟 Skills 热点（对口字节“Agent Harness”岗 JD）。

### bytedance/deer-flow
- 工具设计：LangGraph 多 Agent（规划/研究/编码子 Agent）+ 沙箱 + 记忆 + MCP + Skills 目录。工具通过 MCP 或 skill 动态接入。
- 评测：社区在讨论 SWE-bench 等长任务基准（issue #2820），尚无统一评测。
- 借鉴：把我们的 RDKit 工具做成 MCP server，可以直接接入 deer-flow 演示——“我的工具能被字节开源框架调用”是很好的面试话题。

### 其他 RDKit + LLM 项目
- rdkit-mcp-server / CoChem-Agents：证明“RDKit→MCP→通用 Agent”路线可行，第二阶段可参考。
- jincinga24-hue/chem-agent：小 benchmark（23 题、按子领域分类）的组织方式值得照抄。
- ChemLLMBench：评测题型（性质预测、名称转换、反应预测）可作为出题参考。

## 对本项目的结论
1. 第一版保持简单：OpenAI 兼容 function calling 手写主循环，不引入 LangChain，便于用户讲清原理。
2. 评测双指标：答案准确率（数值容差/精确匹配，程序判定）+ 工具选择正确率。
3. 加分项顺序：安全检查工具 → MCP 封装 → 接入 deer-flow 演示 → SKILL.md。
