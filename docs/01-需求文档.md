# 化学 Agent 项目 · 任务需求文档
负责人：humy（项目管理）｜用户：周宸锐｜创建：2026-10-18

## 目标
做一个能真实运行、带量化评测的化学 Agent，作为 2027 年 3 月投递字节 ByteIntern（Agent 开发 / 评测方向）时的核心简历作品。

## 约束
- 学期内课业优先，开发时间放在课余和寒假。
- 主力工具：Codex（额度快到期，先集中用掉），备选 DeepSeek 等。
- 所有指标必须真实跑出来，不编造。
- 留学因费用原因不考虑，只走就业路线。

## 功能需求
1. 工具层：用 RDKit 实现分子量、LogP、类药性（Lipinski 规则）、SMILES 校验、子结构匹配等工具。
2. Agent 层：大模型接收自然语言提问，自主选择并调用工具（function calling）。
3. 评测层：30–50 道带标准答案的化学题，脚本自动打分，输出准确率和工具调用正确率。
4. 交付：GitHub 公开仓库、README、演示截图或录屏。
5. 延伸：给字节开源项目（deer-flow 或 trae-agent）提交至少 1 个被合并的 PR。

## 验收标准
- clone 仓库后一条命令就能跑通 demo 和评测。
- README 里写明真实评测结果。
- 用户本人能讲清每个模块的原理。
