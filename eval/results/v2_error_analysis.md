## 只改一处

位置：`chem_agent/agent.py` 的 `SYSTEM_PROMPT` 末尾，新增以下一条要求：

> 仅检查 SMILES 有效性时，最多调用一个工具一次；确认无效后直接说明输入无效，不重复验证，不猜测或举例补全、修改可能的分子结构。

选择理由：两个工具最终复用了相同的 RDKit 解析检查，重复调用没有增加有效证据；题目明确禁止猜测结构。希望减少冗余验证与回答中的结构猜测，同时保留对其他题型的表现。基线自动评分已满分，因此本轮不是以“准确率必然上升”为前提；下降或持平都照实保留。

两轮之间只增加上述提示词；工具描述、工具计算实现、题集、评分逻辑和请求参数保持一致。两轮之前完成的公共准备是 token 统计、预算保护和模型兼容更新：账号模型列表已无 `deepseek-chat`，根据[官方更新日志](https://api-docs.deepseek.com/zh-cn/updates/)统一改用 `deepseek-flash` 非思考模式，单请求输出上限 2048。两轮均使用该设置，不能将它与旧版 deepseek-chat 的 40 题结果混作同一实验。

## 预算和数据来源

- 官方价格来源：[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核对日期 2026-10-19。Flash 每百万 token 高峰输入缓存命中 0.04 元、未命中 2 元、输出 8 元；空闲时段为一半。
- 预算采用更保守口径：所有输入按高峰未命中价，输出按高峰价；不计任何折扣。每次请求先预留 2.2 元上界，收到实际 usage 后结算；未知用量保留预留额，余额不足即停止后续请求。
- 先单独执行前 5 题：输入 12,858、输出 425、合计 13,283 tokens；费用上界 0.029116 元。按平均用量外推一轮 60 题约 0.349392 元、两轮约 0.698784 元，连试跑约 0.7279 元。估算低于 20 元后才启动完整评测。估算明细见 `v2_s4_20261019/budget_estimate.json`，它不是实际账单。
- 原始记录保存每次 API 返回的 usage、模型名和 fingerprint，以及每题累计 token；无 usage 时明确标为不完整，不能算作零费用。前后对比只取两份完整结果；试跑只参与本步费用核算。
